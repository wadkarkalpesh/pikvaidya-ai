# PikVaidya AI - Data Pipeline

This directory is organized for dataset storage, transformation scripts, and preprocessed assets.

## Directory Structure
- `raw/`: Unprocessed plant pathology imagery, soil reports, and agronomic knowledge base documents.
- `processed/`: Normalized, augmented, and segmented image datasets, embeddings, and tokenized advisory texts.

## Note
Raw and processed dataset binaries should not be committed directly to Git. Instead, store manifests, dataset cards, or cloud download scripts here.
