# PikVaidya AI - Frontend Application

This directory will host the client-facing user interface for the **PikVaidya AI** agricultural platform.

## Planned Features
- Multi-language support (Marathi / English)
- Farmer onboarding, login, and profile management
- Interactive Farm and Crop Cycle dashboards
- Image capture & upload for crop disease diagnostics
- Visual XAI heatmaps (Grad-CAM) and actionable advisory cards
- Expert referral consultation portal

## Technology Stack (Planned)
- React / Next.js or Vite
- TailwindCSS / Modern Vanilla CSS design system
- State management & Axios API client
