# PikVaidya AI - AI & Machine Learning Services

This directory will contain the AI / ML microservices, pipelines, models, and explainability algorithms.

## Planned Modules
1. **Disease Detection & Classification**:
   - Deep Convolutional / Vision Transformer architectures trained on multi-crop plant pathology datasets.
2. **Severity Estimation**:
   - Automated crop damage severity assessment and lesion percentage calculation.
3. **Multimodal Fusion**:
   - Integrating leaf imagery, meteorological data, and soil metrics for contextual diagnosis.
4. **Explainable AI (XAI)**:
   - Grad-CAM heatmap visualization and SHAP feature importance.
5. **Agricultural RAG**:
   - Retrieval-Augmented Generation for agronomy advisory, fertilizer schedules, and treatment protocols in Marathi and English.
6. **ORI Orchestration Agent**:
   - Intelligent multi-agent pipeline directing queries to appropriate diagnostic models and advisory engines.
